Shortest Job First

Non-Preemptive  ·  Optimal Average Waiting Time

Algorithm Explanation

Shortest Job First (SJF) selects the process with the smallest burst time from the ready queue. It is proven to give the minimum average waiting time among all non-preemptive algorithms.

At each scheduling event, the CPU picks the shortest available job. If two jobs have equal burst time, FCFS order (arrival time) is used as a tiebreaker.

Drawback: It can cause Starvation — long processes may never get CPU time if short processes keep arriving. Requires knowing burst time in advance.

  • Non-Preemptive
  • Optimal Avg Wait
  • Burst-Time Based
  • Possible Starvation
  • Look-Ahead Required
